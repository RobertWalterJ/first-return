# PWA audit, 3 November 2026: first-return

Short version: one problem found and fixed. Reinstall needed? **No.**

Jargon, one line each:
- **Manifest**: the small file that tells Chrome the app's name, icons and identity.
- **Service worker**: the script that keeps the app working offline.
- **Shared origin**: all your apps live at robertwalterj.github.io, so they share storage.

## What was checked

All nine rules, in `docs/` and the source in `src/`.
`docs/index.html` is generated by `build.py` from `src/`. I did not touch it.
`docs/manifest.webmanifest` is not generated (nothing in `build.py` writes it), so I edited it directly.

## Findings

| Rule | Result |
|---|---|
| 1. Manifest `id` | **Broken.** No `id`. Fixed: added `"/first-return/"`. |
| 2. `scope` and `start_url` | OK. `start_url` is `./`. There is no `scope`, so it defaults to the app folder. Unchanged. |
| 3. Activate deletes only own caches | N/A. The only service worker is the third-party `coi-serviceworker.js`. It has no caches and deletes nothing. |
| 4. No global `caches.match()` | OK. The page opens `first-return-models-v1` by name. |
| 5. Manifest never cache-first | OK. Nothing caches it. |
| 6. Icons | OK. 192, 512, maskable 512 (art at about 67 percent) and an SVG. |
| 7. Storage names | OK. localStorage keys start `firstreturn.`. IndexedDB is `first-return-session`. Cache is `first-return-models-v1`. |
| 8. `addAll` size | OK. Not used. |
| 9. Navigation handling | N/A. The worker passes requests through and never serves a cached page. |

## What I changed

- `docs/manifest.webmanifest`: added `id`. Nothing else.

## Checks run

- Manifest parses as JSON.
- No build or test run was needed. `build.py` does not write the manifest.

## Notes (not rule breaks)

- The app has no offline shell. The service worker only adds the headers the 3D parts need. The 18 MB models are cached by the page in `first-return-models-v1`.
- Nothing ever deletes old `first-return-models-v1` data. That is safe for neighbours, but it grows. If the model files change, use a new name such as `first-return-models-v2` and delete only that exact old name.

## Reinstall needed?

**No.** The `id` I added is the one Chrome already works out from `start_url` (`/first-return/`), so the installed app keeps its identity.
